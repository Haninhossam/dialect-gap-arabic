# Results log

Every run is appended automatically by `dialectgap.tracking.log_run`.
Full records (resolved config, pip freeze) live in `results/runs.jsonl`.
`data_version` = sha256 of the item files used; `git` = commit (`-dirty` = uncommitted changes).
